UI routes and MCP use this same service. All sixteen MCP tools have typed input/output schemas and annotations. Stdio is read-only by default, with explicit --write permission. Host/Origin validation and JSON size limits are enabled.

External agents can author workflows without Codex, browser automation or the visual server process. The editor opens returned ?workflow=<id> URLs, previews associated assets and rejects stale saves after MCP changes. execute_local is authorized as a write and refuses any graph containing a generative node.
