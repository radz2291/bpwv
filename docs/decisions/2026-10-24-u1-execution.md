# U1 execution foundation ADR

Status: implementation decision under the owner's U1 authorization. Baseline d3296549676e942ae402fcee7ea570d8fc51a16e. Recorded before persistent implementation.

Universal documents use schemaVersion 2 with the existing workflow identity/revision/nodes/edges/groups envelope. Only `u.input`, `u.transform`, `u.invoke`, `u.output` version 1 are operational. WorkflowService remains the sole graph authority and uses the same workflows/revisions tables. Schema 1 retains its registry, executor, historical hashes and provider bridge. Mixed documents and future schemas fail closed; no conversion is automatic.

U1 types are text, finite number, boolean, trusted bounded record and managed PNG image. Ports carry type, schemaRef, role and single cardinality. Missing optional bindings are absent, never coerced to null. Collections and later scheduling primitives are explicitly unsupported. Trusted code and manifests are registered at composition time; document JSON cannot install handlers. Semantic hashes include configs, pinned contracts and edges, exclude name/label/position/groups/revision, and use pinned json-canonicalize 2.0.0 (RFC 8785) and SHA-256 with a versioned digest domain. Text is UTF-8 without normalization; reject unsupported/nonfinite JSON.

Artifacts have immutable UUID version IDs, a stable workflow/operation/port family, positive sequential version and predecessor, content hash, parent role bindings, run/attempt/producer/output/snapshot identities and local/imported provenance. Every computed output materializes a version. Output(return) aliases its parent's immutable version. Binary content hashes actual PNG bytes. New additive tables hold artifacts, runs, attempts and migration ledger; legacy columns/positional INSERT statements are untouched.

Managed bytes live under the configured data root in generated content-addressed blob paths. Validate size/signature before import. Stage a uniquely named temporary file then atomic rename before transactional artifact completion. A crash before database commit can leave an unreferenced immutable blob; it cannot expose a completed artifact. No garbage collection in U1. Reads verify bytes/digests and fail visibly on corruption or missing content. Imports accept bounded bytes, never workflow-provided filesystem paths or remote URLs. Legacy upload and download routes must use the configured root too.

Runs freeze the saved document, resolved contract hashes and inputs. Persist run plus attempts before handlers. Serial DAG dispatch is registry based; failed dependencies block descendants, unrelated nodes may continue. Terminal updates use compare-and-set. Workflow-scoped idempotency keys bind exact revision and snapshot; duplicate delivery returns the original run, a mismatched key conflicts. Interrupted running attempts become interrupted on recovery without replay, requiring a new explicit execution/key. No external retries, no exactly-once external claim. Terminal records are immutable. Verify restored graph/producer/attempt/parent/hash relationships, not JSON parsing alone.

Manifests pin adapter/capability/version, typed ports/roles, strict setting schemas, discovery/expiry and effect scope. U1 local effects permit bounded computation and managed artifact persistence only. `CREATIVE_FLOW_ALLOW_LOCAL_EXECUTION=1` is a separate, default-denied process policy in addition to MCP write authority. Import also requires this policy. HTTP remains single-user loopback; no general filesystem, network, upload, publish or spend effects. External Weave manifests may be inspected/planned as blocked; no executor or synthetic generated assets. Existing quote/structured approval and credit stops remain unchanged.

Migration is additive, ledgered, transactional and rerunnable. Test fresh and legacy clones plus injected failure rollback before serving new formats. Capture consistent SQLite VACUUM backup and file digests first (data/u1/before.sqlite and private before-files.json). Old binaries are not promised to understand schema 2: rollback means stop processes, preserve the new root, restore verified pre-U1 backup and original binary. Do not drop tables or rewrite user documents. Tests use explicit isolated DB/media roots including Inspector server-config environment.

Remaining Branch/Iterate/Approve/Subflow and external execution are deferred. Real ChatGPT gate requires an actual connected call; local Inspector is separate evidence.
