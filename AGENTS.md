## Approved product direction — Universal Workbench (Option C)

The owner approved Option C on 24 October 2026 as the intended **future architecture**: universal typed operations, reusable recipes, first-class versioned artifacts and a synchronized AI/visual workbench. Read [docs/universal-workbench/README.md](docs/universal-workbench/README.md) and its linked contracts, experience, migration gates and Codex handoff **before** proposing new node families or changing workflow architecture. New tasks should be expressed as recipes, prompt configurations, transforms, typed media roles or provider capability manifests, rather than new project-specific core node kinds. A new primitive requires an explicit semantic necessity, compatibility impact and owner review.
